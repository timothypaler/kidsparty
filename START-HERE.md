# Leo’s Wild Five — Jungle Party — complete source code

This export includes all HTML, CSS, JavaScript, images, local fonts, music and attribution files from the current published invitation. No build or package installation is required.

## Preview locally

1. Extract this ZIP.
2. Open a terminal in the extracted folder.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000 in your browser.

## Edit or host

- Start with index.html, style.css and the JavaScript files.
- Keep the assets folder beside index.html.
- To host on a static website service, upload the contents of this folder.
- RSVP is currently a device-local sample. It does not submit to a host or Google Sheet.
- Names, dates and venue details are illustrative.
- Keep the bundled photo, font and music credits. Check rights for your intended use of any supplied wedding music.
